# 基于盲道识别与人工势场法的自主导盲小车系统

本项目结合嵌入式系统与人工智能技术，设计并实现了一套具备自主寻盲道行驶、智能避障及手持端人机交互的导盲机器人系统。相关学术成果已公开发表于省级科技期刊《电子制作》。

---

## 🌟 项目亮点与技术特色
- **多主控异构协同**：采用 **树莓派 4B+ (Linux)** 作为车载算力核心，配合 **STC 双单片机 (8051架构)** 构建低功耗手持交互终端。
- **轻量化 CNN 视觉循迹**：在树莓派端部署轻量级卷积神经网络模型进行盲道实时辨识，结合 OpenCV 边缘提取实现小车对中行驶。
- **主动避障路径规划**：基于车前多路超声波测距，利用**人工势场法（APF）**动态计算引力与斥力合力，实现平滑绕障与原轨迹回归。
- **混合无线交互网络**：车端与手持端通过 **蓝牙（HC-05）** 远距透传，手持端双 MCU 采用 **ZigBee（DL-20）** 协同，并集成 **GSM（SIM800C）** 紧急短信救援。

---

## 🛠️ 系统架构与硬件方案

### 1. 车载控制平台（小车端）
- **核心主控**：Raspberry Pi 4B+ (负责图像处理、路径规划与电机调速)
- **视觉采集**：广角 USB 摄像头 (480P)
- **环境感知**：HC-SR04 超声波测距传感器组 (盲区 1.4cm，探测距离 50cm)
- **动力驱动**：L298N 电机驱动模块 + 1:48 减速 TT 双差速马达组

### 2. 人机交互终端（手持端）
- **双核心架构**：
  - `IAP15F2K60S2`：负责蓝牙通信接入、OLED 距离显示与 SIM800C 短信模组驱动
  - `STC89C52`：负责矩阵按键检测与 BY8301-16P 语音模块播报驱动
- **无线模块**：HC-05 蓝牙模块 (车机互联) + DL-20 ZigBee 模块 (板间通信)

---

## 🧠 核心算法与软件实现

### 1. 盲道辨识与偏航校正
- **模型结构**：基于 TensorFlow 搭建 2 级卷积 + 2 级池化 + Flatten + 2 级全连接网络，测试集准确率达 99.6%。
- **对中决策**：OpenCV 二值化提取盲道边缘拟合中线，将画面栅格化为 10 等份；依据盲道中线与屏幕中线的偏差阈值实时调整电机差速。

### 2. 人工势场法主动避障 (APF)
- 构建目标点引力场与障碍物斥力场函数，设定引力系数 $K=1.0$、斥力系数 $q=0.8$、作用范围 $\rho_0=3$。
- 根据超声波测距实时更新合力向量，控制左右电机差速转弯避障，脱离障碍物影响后平滑回归主盲道。
